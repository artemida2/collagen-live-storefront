# Collagen Live — сайт официального дистрибьютора

Лендинг с корзиной для дистрибьютора **Collagen Live Wellness** — пищевого коллагена
в форме желе. Продукт, состав и цены принадлежат производителю
([collagen-live.ru](https://collagen-live.ru/)); этот репозиторий — витрина дистрибьютора.

## Стек

Vite 8 · React 19 · Framer Motion (`motion`) · Lenis · TypeScript. Без UI-библиотек:
вся вёрстка и все компоненты написаны под этот проект.

```bash
npm install
npm run dev      # http://127.0.0.1:5190
npm run build
npm run preview  # http://127.0.0.1:5191
```

## Как устроена страница

Одна фиксированная видео-подложка на всю страницу; секции поверх неё — непрозрачные
плиты, а «окна» в видео — это дырки в этих плитах, а не второй проигрыватель.
Отсюда главное правило вёрстки: **секция, внутри которой есть окно, не должна красить
собственный фон** — иначе фон закроет дырку. Так сделаны два места:

- «живая» половина сравнения в секции `Почему живой`;
- банка в зелёной секции `Технология` — силуэт вырезан из плиты цвета секции
  (`Jar.tsx`, `fill-rule="evenodd"`), а крышка, резьба, уровень налива и этикетка
  дорисованы поверх видео.

### Видео и производительность

| файл | где | когда играет |
|---|---|---|
| `live.mp4` | фиксированная подложка | пока не дошли до секции `Технология` |
| `dry.mp4` | половина «Порошок» | только в зоне видимости |
| `jar.mp4` | внутри банки | только в зоне видимости |

Одновременно декодируется не больше двух. **Ниже 760 px (и при `prefers-reduced-data`)
видео вообще не попадают в DOM** — вместо них отдаются постеры, см. `useStills()`
в `src/lib/hooks.ts`.

Ни на одном полноэкранном слое нет `mix-blend-mode`: он складывает всю страницу
в одну композиционную группу и перерисовывает её на каждом кадре скролла.
Нижние секции помечены `content-visibility: auto`.

## Две сборки, один сайт

В репозитории два проекта. В корне — лендинг на Vite/React, он собирается в
`dist/`. В `pages/` — контентные страницы на Astro, они собираются в
`pages/dist/`. `scripts/merge.mjs` кладёт вторую поверх первой и пишет
`sitemap.xml`, обходя то, что реально оказалось в `dist/`, поэтому карта сайта
не устаревает, когда страницу заводят через админку.

`npm run build` делает все три шага. Отдельно лендинг — `npm run build:landing`,
отдельно страницы — `npm run dev:pages`.

Лендинг сознательно не переносился на Astro: это одна сплошная скролл-сцена с
фиксированной видео-подложкой, её нечего резать на острова. Контентные страницы
сознательно не делались на React: это документы, их нечего рисовать
джаваскриптом.

## Что редактируется через `/admin`

Sveltia CMS, вход по личному токену GitHub. Движок лежит копией в
`public/admin/sveltia-cms.js`, а не тянется с CDN: скрипту передают токен с
правом записи в репозиторий.

| Коллекция | Файлы | Адреса |
|---|---|---|
| Товары и цены | `src/content/products/*.json` | главная, секция магазина |
| Города доставки | `content/goroda/*.md` | `/dostavka/<адрес>/` |
| Разборы и сравнения | `content/razbory/*.md` | `/razbor/<адрес>/` |
| Инструкции | `content/instrukcii/*.md` | `/kak/<адрес>/` |
| Прайс-листы | `content/ceny/*.md` | `/ceny/<адрес>/` |

| Свободные страницы | `content/stranicy/*.md` | `/stranica/<адрес>/` |

Свободная страница собирается из блоков: текст, таблица «параметр — значение»,
нумерованные шаги, вопросы-ответы, карточки, мини-прайс, цитата, картинка,
зелёный блок с кнопкой, сноска. Набор закрытый и оформление выбирается из трёх
вариантов (`standard`, `narrow`, `promo`) — конструктор, которым можно собрать
что угодно, рано или поздно соберёт что-то стыдное, а собирает эти страницы не
дизайнер.

Флажок «Скрыть страницу с сайта» (`draft`) убирает страницу из сборки целиком:
маршрут не генерируется и в карту сайта не попадает, но текст остаётся в
репозитории. Это намеренно строже, чем `noindex`, который оставляет страницу
открытой всякому, у кого есть ссылка. Чтобы убрать из админки целый шаблон,
достаточно дописать `hide: true` в его коллекцию в `config.yml`.

Поле «Адрес страницы» заполняется латиницей и становится именем файла и куском
ссылки; кириллица в адресе превращается в нечитаемую строку из процентов.
Схемы полей описаны дважды и намеренно: в `pages/src/content.config.ts` — для
сборки, в `public/admin/config.yml` — для формы редактора. Расходятся они
шумно: Astro падает на непрошедшей проверке, а не публикует сломанную страницу.

## Структура

```
src/
  components/   секции страницы, корзина, банка-вырез
  data/         catalog.ts — товары и цены; content.ts — состав, польза, FAQ;
                legal.ts — реквизиты продавца и юридические документы
  lib/hooks.ts  Lenis, media-queries, воспроизведение в зоне видимости, состояние корзины
  styles/       tokens.css → base.css → app.css (последний включает адаптив)
public/media/   видео и фотографии клиента, ужатые под веб
```

`PRODUCT.md` — продуктовая правда и подтверждённые решения. `DESIGN.md` — дизайн-система.
